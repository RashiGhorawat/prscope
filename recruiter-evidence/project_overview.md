# PRScope — Project Overview

## Problem
Developers need help identifying risky code changes
and determining which tests should be run.

## Solution
PRScope is an AI-powered Pull Request Risk Analyzer
that analyzes code changes, estimates risk, and
recommends relevant tests.

## Planned Tech Stack
- Python
- FastAPI
- GitHub API
- PostgreSQL
- React
- Machine Learning

## Current Progress
- Created project structure
- Set up Python virtual environment
- Built a FastAPI application
- Added home and health-check endpoints
- Verified the API using Swagger UI

## Upcoming Features
- GitHub pull request integration
- Code dependency analysis
- ML-based risk prediction
- Test recommendations
- Interactive dashboard
